# a-ratz.github.io

GitHub Pages mirror of [Infinite Loop](https://github.com/a-ratz/infinite-loop),
my blog of interactive essays and portfolio pages.

The `pages` workflow builds the site from `a-ratz/infinite-loop` every night and
on demand (`gh workflow run pages -R a-ratz/a-ratz.github.io`). This repository
holds no site files of its own.
